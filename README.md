# Free Client-Side Utility Tools

A curated suite of fast, privacy-first, zero-login browser utilities for developers, contractors, and digital businesses. All calculations execute 100% locally in the browser with zero data tracking or server storage.

Hosted live at: **[locolory.store/tools](https://locolory.store/tools)**

---

## 🛠️ Available Web Utilities

### 💻 Developer & DevOps Utilities
- **[Unix Timestamp Converter](https://locolory.store/tools/unix-timestamp-converter)** - Convert epoch seconds/ms to human dates across timezones with live clock.
- **[Cron Expression Generator](https://locolory.store/tools/cron-expression-generator)** - Interactive 5-part and 6-part cron schedule builder and English explainer.
- **[JSON to TypeScript & Zod Converter](https://locolory.store/tools/json-to-typescript-converter)** - Convert raw JSON payloads into clean interfaces and validation schemas.
- **[CIDR Subnet Calculator](https://locolory.store/tools/cidr-subnet-calculator)** - IPv4 subnet masks, usable host ranges, and AWS VPC allocations.
- **[Base64 File & Image Converter](https://locolory.store/tools/base64-file-converter)** - Encode and decode text, files, and images to Data URIs locally.
- **[cURL to Code Converter](https://locolory.store/tools/curl-to-fetch-converter)** - Turn cURL commands into JavaScript fetch(), Axios, and Python requests.

## 🔒 Privacy & Architecture
All tools run strictly on client-side Web APIs, HTML5 Canvas, and local JavaScript. No personal data, files, or calculations are transmitted to any backend server.
